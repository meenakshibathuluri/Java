1.programming language :
-> set of instructions given to computer to perform specific task.
2.generations of programming languages :
there are 5 level of programming language
->machine language(1940s-1950s): the native language of the processor ,composed entirely of binary code(0s and 1s).
->assembly language(1950s-1960s):a low-level languages that introduces mnemonics(like add, mov, sub)instead of raw binary numbers
->high-level languages(1960s-present):general purpose languages that use English like statement, structural formatting etc.
->declarative/domain-specific languages(1970s-present):non-procedural languages built around a declarative paradigm
->artificial intelligence(1980s-beyond):programming architectures built around constraint-based and logic solving
